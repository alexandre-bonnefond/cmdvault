cmdvault · getting started

Remember two things: save and Ctrl+G

Type save right after a command worth keeping. Press Ctrl+G when you need it back. Everything else on this page is an extra you can pick up later.

Your first five minutes

  1. Open a new terminalor run sb in the ones already open, so bash loads cmdvault. Run tmux source-file ~/.tmux.conf once for the tmux popup.
  2. Run something you will need again, then type saveAnswer the questions: the command (edit it if you like), a description, tags. Enter skips the optional ones.
  3. Press Ctrl+G and type a few words of the descriptionEnter puts the command on your prompt. It never runs on its own; you press Enter to run it.

save

Keep the command you just ran

Turn the parts that change into <placeholders>. For each one you either list values to choose from (notes, src, ~/Documents), give a command that prints them (!docker ps --format {{.Names}}), or leave it empty to type it when you use it.

Keep a sequence as one recipe

Shows your last 3 commands, all selected. Tab drops the ones you don't want, Enter saves the rest joined with && \, so the recipe stops at the first command that fails.

Ctrl+G

In bash: onto the prompt

If you already typed something, it becomes the search. Pick an entry, fill the placeholders, and the finished command replaces the line.

Ctrl+A then ?

In tmux: pasted into the pane

Works in any pane, including an ssh session on a drone or a program that is not bash, because tmux pastes the result into the pane you came from. Multi-line recipes are pasted without running.

Anywhere: copied to the clipboard

The cheatsheet has a Terminal section; its first row opens the vault in rofi. Enter asks for each placeholder, then copies the command. Rows marked ▶ have a recording, Ctrl+P plays it.

cv --tldr tar

Not saved yet? Search tldr or cheat.sh

The tldr examples for a command, with their arguments as placeholders. cv --cheatsh QUERY does the same with cheat.sh. If the result is good, Ctrl+X s keeps it in your vault.

Record a session and link it to an entry

Opens a recorded shell; exit stops it. Then save the commands you typed as a new entry, or link the recording to an existing one. Replay with cmdvault play NAME; cmdvault gif NAME makes a GIF.

Where your commands live

Plain text files in their own git repo, ~/git/cmdvault-cheats, one file per first tag. Every save is a local commit.

To use the same vault on another machine, add a remote once (git -C ~/git/cmdvault-cheats remote add origin URL), then run cmdvault sync to pull and push.

cmdvault ls lists everything, cmdvault --help shows all commands.
